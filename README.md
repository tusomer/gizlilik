# gizlilik

Zone Oyun oyunlarının gizlilik metinleri. Yayın: https://tusomer.github.io/gizlilik/

Bu depoda yalnız gizlilik metinleri durur: kod, görsel ve oyun dosyası yok. Yeni oyun için `<oyun-adi>/index.html` (Türkçe) ve `<oyun-adi>/en.html` (İngilizce) eklenir, kök `index.html` listesine bir satır girer.
